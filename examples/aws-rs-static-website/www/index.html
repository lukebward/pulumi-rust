Static website on S3 and CloudFront

Hello from Pulumi and Rust

This page was uploaded from a www/ directory by a Pulumi program written in Rust. It lives in a private S3 bucket — you are reading it through a CloudFront distribution, which is the only principal allowed to fetch it.

Edit www/index.html and run pulumi up again to publish a change, then invalidate the CDN's cache to see it straight away.
