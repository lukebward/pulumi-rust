Hello, World from Pulumi!

This page is served by Azure App Service. It was zipped out of the app/ directory, uploaded as a blob, and handed to the site through the WEBSITE_RUN_FROM_PACKAGE setting by a Pulumi program written in Rust.

The same program created an Azure SQL database and passed its connection string to this app as a secret. The runtime exposes it as the SQLAZURECONNSTR_db environment variable — this static page does not read it, but an application deployed in its place would.
